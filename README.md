# 侧栏编程（dsh-side-coder）

右栏停靠式代码编辑器 + AI 改动实时对比，仿 Trae 体验。

## 功能

- **真右栏停靠**：与对话同屏，宽度由右栏分隔条拖动；排布为 对话 | 编辑器+对比区 | 文件树（文件树贴最右）。
- **编辑器**：Monaco 编辑器，文件树/文件链接尾巴打开文件，Ctrl+S 保存。
- **实时对比**：AI 每次改文件自动留下改动前后全文，红删绿增呈现，◀ ▶ 可翻历史改动。
- **自动弹出**：对话里出现新文件改动时约 2 秒内自动展开右栏、对比区直跳最新改动（「弹出」按钮点灭即只手动打开）。
- **跟随**：「跟随」亮着时对比区自动跳最新改动，点灭后手动翻。
- **文件列表管理**：「列表」按钮收起/展开文件列表；右键菜单支持 复制相对路径 / 复制绝对路径 / 添加到对话（@文件） / 复制 / 剪切 / 粘贴 / 删除。
- **Markdown 只读预览**：打开 `.md` / `.markdown` / `.mdx` 文件后，点面板头部的「预览」按钮，编辑器与 Vditor 渲染结果切换。支持 GFM 表格、任务列表、KaTeX 数学公式、Mermaid 流程图、代码高亮；跟随系统暗色主题。预览用 Vditor 4.0.0 渲染，全部资源以内置资产同源加载，不产生任何外部网络请求；非 Markdown 文件「预览」按钮自动置灰。

## 开关一览

| 按钮 | 位置 | 作用 |
|---|---|---|
| 弹出 | 面板头部 | 新改动自动弹出右栏（默认开） |
| 列表 | 面板头部 | 收起/展开文件列表（默认开） |
| 跟随 | 面板头部/对比区 | 自动跳最新改动（默认开） |
| 对比 | 面板头部 | 收起/展开对比区 |
| 预览 | 面板头部 | Markdown 文件切到只读预览（Vditor 渲染） |

四个面板开关的状态会记住（存在浏览器本地）：面板重新打开、自动弹出、页面重载后都按上次状态恢复，不再回到默认值。自动弹出时也不再强行翻开「对比」，尊重用户点灭的状态；用户手动点开「对比」时才直跳最新改动。预览开关是临时的，切换文件或退出面板即复位。

## 安全说明（Markdown 预览）

- 渲染启用 Lute 内置 HTML 净化（`markdown.sanitize=true`）：实测剥离 `<script>`、事件属性（`onerror`/`onload`/`onclick` 等）、`javascript:` / `data:` URL、`<iframe>` 事件载荷。
- 已知残余：Mermaid 渲染由 Vditor 以 `securityLevel:"loose"` 硬编码驱动（Vditor 内部实现），Mermaid 图内的 HTML 标签会被插值保留（执行脚本不触发，但 `<img src>` 等标签会留在 SVG 内）。作为只读、本机同源工具，风险有限；不把陌生来源的 Markdown 直接打开为妙。
- 相对路径图片（`![x](./img.png)`）当前**不解析**：预览容器按页面 URL 解析相对路径，而非 Markdown 文件所在目录，会 404 不显示。如需支持相对图片需新增后端认证静态端点，当前版本明确不支持（见「预览数据源」）。

## 预览数据源

「预览」读取的数据源优先级：若当前活动编辑器就是被预览的 Markdown 文件，直接用 Monaco 编辑器的实时内容（含未保存的编辑）；在对比/其他标签下打开预览则回退到打开文件时的已保存内容。

## 结构

- `lib/index.js` —— 后台半边：文件读写通道 `/side-coder`、改动记录器（工具事件前后快照、多手牌配对、环形 200 条、记会话归属）。
- `lib/client.js` —— 界面半边：右栏标签页注册、文件树、编辑器、对比区、自动弹出追踪（2 秒间隔）、Markdown 预览（Vditor）。
- `assets/vditor/` —— Vditor 4.0.0 内置预览资产（约 92 文件 / 9.55 MB），经 `/side-coder-vditor` 同源静态路由加载，零外部请求。
- `cordis.patch.yml` —— 自我登记挂载行。
- `debug-events.jsonl` —— 运行后自动生成的调试小账本（黑匣子）：改动不显示时看它即可定位卡在哪一环。
